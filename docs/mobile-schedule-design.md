# 移动端课表工具设计书

## 目标与范围

为齐鲁工业大学学生提供完全本地的课表导入、查看、编辑、备份和班级分享能力。首版优先 Android 移动端，适配教务系统导出的 `.xls` / `.xlsx` 课表，并允许手工维护课程。

首版包含：

- 一周课表、左右滑动切周、周次选择和回到本周。
- 课程详情、添加、编辑、复制和删除。
- 同一课程的多个上课时段，以及全部、单双周和任意周次。
- 教务文件中的“其他课程”转为待安排课程。
- 多课表管理；导入时选择创建或覆盖。
- 每份课表独立设置开学日期、总周数、作息时间、周末显示方式和整日停课日期。
- 本地备份、恢复和调用系统分享面板分享可导入课表。
- 应用启动页可配置为课表、工具箱或上次页面。

首版不包含：单门课程的单日停课、临时调课、提醒、小组件、课表图片分享、云同步和智能合并。

## 导航与页面

底栏仅保留：

1. 课表：高频默认页；无课表时显示导入或新建引导。
2. 工具箱：承载分项成绩、GPA 等工具。
3. 我的：应用设置、关于、更新等。

具体工具页隐藏底栏并显示“返回工具箱”。分项成绩任务记录移入分项成绩工具。

课表页顶部仅保留周次、日期范围、添加按钮和更多菜单。添加按钮直接添加课程；更多菜单包含导入、待安排、切换、管理、设置、导出、新建和删除课表。

课表主体一屏显示当前配置允许的星期列，不横向滚动。左右滑动主体切换上一周/下一周；纵向滚动位置切周后保持。查看非当前周时显示“回到本周”。

## 视觉方向

沿用 LumaTile 蓝色品牌体系：

- 页面背景 `#F4F8FC`
- 主蓝 `#0B76E8`
- 深蓝 `#0758B8`
- 正文 `#18324B`
- 次级文字 `#667D93`
- 暖黄强调 `#FFBE2E`

课程使用固定、低饱和且可读的色板，以柔和底色和深色侧边区分课程。当前日期采用贯穿日期头和网格的蓝色刻度强调，这是课表页唯一的强视觉特征。

## 数据模型

课表与课程分离，课程与上课时段为一对多关系。持久化结构使用带 `schemaVersion` 的整份 JSON，Room 只保存课表元数据和 JSON 内容，保证写入原子性并避免过早关系化。

```ts
interface ScheduleBook {
  schemaVersion: 1
  id: string
  name: string
  academicYear: string
  semester: string
  startDate: string
  totalWeeks: number
  weekendMode: 'auto' | 'show' | 'hide'
  periods: PeriodTime[]
  noClassDates: NoClassDate[]
  courses: Course[]
  updatedAt: string
}

interface Course {
  id: string
  name: string
  code: string
  teachingClass: string
  teachers: string[]
  credit: number | null
  color: string
  note: string
  meetings: Meeting[]
}

interface Meeting {
  id: string
  weeks: number[]
  weekday: number | null
  startPeriod: number | null
  endPeriod: number | null
  location: string
  teachers: string[]
  source: 'imported' | 'manual'
}
```

`weekday` 或节次为空的时段即为待安排项。教学班号是导入时合并课程的首选键；缺失时使用课程代码和名称回退。教师不参与课程身份判断。

## 文件导入

- Android 最低版本为 8.0（API 26），以使用当前受维护的 Apache POI 安全读取教务导出的旧式 XLS；不为兼容更旧系统引入停止维护的解析器。

Android 通过系统文档选择器取得文件，不申请广泛存储权限。工作簿解码限制文件大小、工作表范围和文本总量，解析后转换为平台无关的行、单元格和合并区域，再由共享核心完成课表语义解析。

解析规则：

- 在前 10 行寻找星期表头，不硬编码工作表名。
- 使用合并区域确定课程覆盖的起止节次。
- 按 `◇` 拆分普通课程字段，并按字段标签去重。
- 将 `1-12周`、`5-9周(单)`、`6-12周(双)` 转换为明确周次数组。
- 将“其他课程”解析成待安排时段，保留课程、教师和周次。
- 学号不进入持久化数据；姓名仅用于建议课表名称。

导入完成后先显示确认页，包括学期、课程数、已安排时段、待安排项、警告、开学日期和总周数。用户选择创建新课表或完整覆盖已有课表；不做智能合并。

## 手工编辑

添加课程页包含课程名称、颜色和可折叠的课程信息，以及一个或多个时段。每个时段可以选择周次、星期、起止节次、教室和教师，并支持复制、删除或标为待安排。

周次选择器提供全部、单周、双周快捷操作及逐周切换。内部只保存最终周次数组。节次选择器先选星期，再选开始和结束节次，禁止结束节次早于开始节次。

课程冲突只提示，不阻止保存。

## 周末显示

- `auto`：存在当前周有效的周末课程时显示周末，否则显示周一至周五。
- `show`：始终显示周一至周日。
- `hide`：始终显示周一至周五；周末课程仍在详情和管理页可见，并提示当前被隐藏。

## 本地存储与分享

Room 使用单表保存多份课表，每条记录包含 ID、名称、更新时间、是否当前和 JSON 内容。新增、覆盖、编辑和删除均在事务中完成。

导出的分享文件使用 `*.lumatile-schedule.json`，包含课表、课程、时段、作息、停课日期和数据格式版本，不包含姓名、学号、成绩、任务记录、登录信息或全局应用设置。导入备份同样进入确认页并选择创建或覆盖。

## 启动页设置

全局设置 `startPage` 支持：

- `schedule`：优先打开当前课表；无课表时显示课表引导。
- `toolbox`：打开工具箱。
- `last`：恢复上次一级页面，默认回退到课表。

## 验证

- 共享核心测试周次解析、单双周、当前周计算、停课日期、周末自动显示、冲突检测和备份校验。
- Android 测试文件大小、类型、恶意结构、Room 覆盖事务和分享内容脱敏。
- 移动端构建检查 TypeScript，人工验证小屏、深色模式、系统字体放大、切周手势和底部面板。
